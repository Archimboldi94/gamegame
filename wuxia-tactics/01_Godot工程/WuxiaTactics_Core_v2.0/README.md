唯一迭代工程；保留 `project.godot → scenes/Main.tscn` 入口。Godot 4.3+，本轮实际验证引擎为 **4.6.3.stable.official.7d41c59c4**。美术为程序绘制的占位菱形地图。

## 启动与操作

Godot导入本目录的 `project.godot`，F5进入B1《渡口截箱》，控制三名队员击败两名劫客。

| 操作 | 按键或鼠标 |
|---|---|
| 移动 | M；悬停预览，左键执行；危险路径二次确认 |
| 普通攻击 | Q；左键敌人 |
| 当前角色三个主动招式 | 1 / 2 / 3；攻击类左键敌人，守关式立即生效 |
| 燕行步 | E；左键合法落点，每次自身行动限一次 |
| 防御 / 调息 | F / R；立即执行，调息每次自身行动限一次 |
| 结束当前单位行动 | Space / 底部按钮 |
| 取消选招 | Esc / 鼠标右键 |
| 日志 / 重开 | 底部按钮 |

确认框中的确认按钮（含原生键盘确认）提交移动；取消不扣资源。重开会使旧确认和等待中的敌方回调失效。

## 当前战斗范围

- 12×12地图，3我方/2敌方；速度交错队列，稳定ID处理同速，下一轮重排速度；每次自身行动6AP。
- 八方向普通移动1AP、泥地2AP；绕开单位与实体障碍，禁止穿封闭斜角；完整路径先验证再逐步结算。
- 自身行动开始恢复1内力，上限12；调息3AP恢复4内力。未命中照付AP/内力，不产生命中效果。
- 概率命中、确定性命中伤害、破甲、防御与护势互斥；护势减伤按floor取整。
- 前侧五邻格控制区、后三格盲区，墙体/封闭斜角阻断控制区；反击和借机共用每轮1RP，反应不递归。
- 同一步脱离多个控制区，仅速度最高的一人借机，同速按ID；后续步可触发其他人。尝试步在借机前扣AP，致死即中止后续路径。
- 破风剑直线多目标独立命中、回锋剑安全后撤、两门测试枪法、震山掌击退、截脉指削减下次AP、守关式及燕行步。
- 攻击预览显示每个受影响目标、资源余量、命中/落空两种反击分支；移动预览显示实际反应者及命中伤害。UI只读取模型，不掷骰。
- 敌人使用相同规则接敌/普攻，路径评分计入借机风险，无路可走时结束行动。胜利、败北与重开已做主场景集成检查。

全部数值仍是GDD的【建议】/【原型】参数。内功槽已保留但为空，尚未实现内功被动、自选构筑、谱库、成长、存档和探索；不把固定B1战斗等同于完整游戏。

## 模块与数据

| 文件 | 职责 |
|---|---|
| `scripts/BattleBoard.gd` | 网格、地形、Dijkstra、近战/射线障碍、轻功路径 |
| `scripts/BattleState.gd` | 唯一状态/命中/伤害/反应结算；只读预览；动作事件 |
| `scripts/EnemyAI.gd` | 规则驱动的接敌与普通攻击 |
| `scripts/BattleUI.gd` | 菱形显示、HUD、键鼠、危险确认、异步敌方行动调度 |
| `data/b1_map.json` | 原B1地形与marker初始部署，未修改地形拓扑 |
| `data/b1_combat.json` | 单位属性、固定三招式/内功槽/轻功槽、技能费用与威力等 |

`BattleState.events`记录本次成功指令的结果（攻击含骰点、命中率、伤害和反应标记），供表现读取；`reset(seed)`从JSON与marker重建全部临时状态。尚未接动作时间轴或事件回放。

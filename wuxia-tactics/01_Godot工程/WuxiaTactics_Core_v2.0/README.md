# 武侠战棋 v2.0：青崖渡 B1 可玩战斗原型

**引擎**：Godot 4.3+（GDScript / GL Compatibility）。这是逻辑和交互原型，美术为脚本绘制的占位菱形瓦片；没有额外素材依赖。

## 启动

1. 用 Godot 项目管理器导入此目录的 `project.godot`。
2. 按 F5 运行，进入《青崖渡》B1《渡口截箱》。
3. 控制三名我方角色，击败两名劫客。
4. 点击底部“重开”可以重新进行战斗。

本交付已完成**地图和规则的静态测试**。**当前交付环境无 Godot 引擎，尚未进行引擎启动实测**；如出现解析/运行错误，请提供Godot错误日志。

## 操作

| 操作 | 按键或鼠标 |
|---|---|
| 查看路径/移动 | M，鼠标悬停预览，左键落点执行；危险路径二次确认 |
| 普通攻击 | Q，选中敌方单位左键 |
| 三门角色专属武学 | 1 / 2 / 3 |
| 燕行步 | E，点击合法落点 |
| 防御 | F，立即消耗2AP |
| 调息 | R，立即消耗3AP，每次行动最多一次 |
| 结束当前单位行动 | Space / 底部按钮 |
| 取消当前选招 | Esc / 鼠标右键 |
| 查看战斗日志 | 点击底部“日志” |
| 重启战斗 | 点击底部“重开” |

## 原型已实现

- 三名我方角色、两名劫客；每轮按速度排序且敌我交错行动，逐名执行，敌人由简单的主动接敌与攻击AI控制。
- AP基础6；普通格/斜向1AP、泥地2AP；Dijkstra八方向寻路；禁止穿越封闭墙角与单位占格。
- 内力上限12，自身行动开始恢复1点，调息+4；普通攻击3AP；防御与守关式互斥。
- 概率命中：技能基础命中+眼力修正−闪避修正+侧背修正−远程掩护修正，最终限制在10%—95%。
- 确定性命中伤害：技能威力+劲力−有效护甲；破甲、护甲加成、护势减伤。
- 角色前方与侧方5格控制区、背后3格盲区；每轮1RP共用自动反击与脱离控制区的借机攻击；禁止反击链。
- 3招式+1内功+1轻功的构筑原则。此关卡先用角色固定的3个技能及燕行步进行验证。
- 剑客破风剑（3格直线群攻）、回锋剑（攻击后免借机后撤）；枪客穿云枪、挑枪；拳师震山掌、截脉指；三人都有守关式。敌方暂用普通攻击。
- 战前队伍、秘籍、精进与探索地图没有接入本关卡，属于后续开发。
- 实时风险预览和结算沿用同一个 `BattleState.gd`，不再由UI单独掷骰或计算命中。
- 战斗结果提示，点击“重开”复位全局局面。

## 技术模块

- `scripts/BattleBoard.gd`：网格、阻挡、地形成本、八方向寻路、轻功跳跃路线判断。
- `scripts/BattleState.gd`：实体、速度队列、AP/内力、命中伤害、五格控制区、自动反击、状态、胜负。
- `scripts/EnemyAI.gd`：逐回合接近最近可攻击位置并尝试普攻。
- `scripts/BattleUI.gd`：菱形地形绘制、HUD、悬停预览、键鼠和危险路径确认、日志及胜负弹窗。
- `data/b1_map.json`：继承v1.9的B1《渡口截箱》12×12地图。
- `tests/CombatTests.gd`：Godot原生无界面规则测试。

## 用Godot运行自动化测试

在此目录下执行：

```bash
godot --headless --path . --script res://tests/CombatTests.gd
```

支持的实际可执行程序名称可能为`godot4`或`Godot_v4...`，以本地安装为准。测试覆盖地形、八方向距离、速度顺序、控制区、借机攻击、调息与胜负。

## 本版已知约束

1. 程序绘制视觉仅用于测试玩法；还没有正式精致像素美术、真实探索场景、动作时间轴或特效。
2. 敌方AI仅主动接敌和普通攻击，不会主动利用技能、策反、撤退或协作包夹。
3. 没有剧情、装备、升级、保存、武学精进和完整战役循环。
4. 前一版GDD对枪的“2格攻防”尚未定义统一数值，本版用“穿云枪/挑枪”为教学暂定技能，不作为最终武学表。
5. 身法、技能AP、初始气血、护甲和伤害仍是**原型参数**，需要进行胜率、回合耗时、流派平衡测试。
6. 当前环境未运行Godot，**不保证完全没有GDScript解析或UI尺寸问题**。

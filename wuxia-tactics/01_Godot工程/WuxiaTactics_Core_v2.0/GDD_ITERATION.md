速度交错、AP、正方形逻辑格/八向普通1AP/封闭墙角限制、概率命中、自动反击与前侧五格控制区、自然恢复加主动调息、三个招式加一个内功槽加一个轻功槽、斜45°视角及简洁情境HUD等不变。独立成长、共用谱库、实时自由探索等原则仍保留，相关系统本轮未实现。

## 【建议】及原型细则的实施口径

| 依据 | 本轮采用的实施细则 |
|---|---|
| 2.7、2.11.3 | 同一步同时脱离多个控制区时仅速度最高者借机，同速按ID；后续步骤可触发其他人。25.3原实现说明中的“每个威胁单位独立RP”保留为每轮资源原则，不解释成同一步全员攻击。 |
| 2.7、2.11 | 本步执行尝试前支付AP，借机先于位置改变；致死停止后续步。反击/借机共用每轮1RP，反应不递归，反应命中修正−10后夹限。 |
| 2.4、2.7 | 近战和控制区遵守封闭斜角与实体阻挡，不隔墙投射威胁。 |
| 2.11.5、25.4 | 护势伤害按floor取整；未命中不消耗防御/护势；防御与护势互斥。 |
| 4.4、4.6 | 回锋后撤、燕行步每次自身行动至多一次；回锋普通攻击本身仍可在资源足够时再施展。 |
| 2.7、25.3/25.4 | B1回锋的安全后撤由技能数据`retreat_safe`显式声明，沿用当前B1原型；后撤采用原实现的自动反方向一格，落点不合法就留原地。自由选择后撤格未实现。 |
| 25.4 | 沿用B1两门恰好2格的测试枪法、2格直线截脉指；不擅自拿早期候选表覆盖B1运行数据。 |
| 24.1、24.2 | UI显示模型只读的命中率、命中后伤害、实际反应者、资源余量；击退/后撤的反击显示命中/落空两分支；危险移动二次确认。 |

6AP、12内力、伤害、AP/内力费用、同速排序等仍是【建议】/【原型】，本轮未改动原单位数值、地图拓扑和B1胜负目标。AOE独立命中沿用原实现，非主目标不反击。

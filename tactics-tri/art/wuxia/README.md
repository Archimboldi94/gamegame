# 《天平之誓》武侠美术试制

日期：2026-10-14。状态：单角色静态试制，供确认新方向与质量基准。主游戏仍使用原有素材；本目录不代表整套美术已完成，也不代表已经通过游戏内验收。

## 风格基准

目标是有生活痕迹的江湖武侠。采用写实人体、工笔式轮廓和克制的厚涂材质，以靛蓝、墨灰、米白、旧皮革和少量赭红构成角色配色。服装用交领、束腰、绑腕、布靴与中国直剑建立身份。避免波斯装饰、欧洲盔甲、仙侠光效和大头玩偶比例。

林砚的识别点：黑发半束髻、靛蓝短外袍、米白内领、赭红腰带、黑鞘直剑、青玉小坠。后续各张图使用本角色立绘作为参照，逐项核对这些识别点。

## 正式资产生产流程

1. 确定一组质量基准：一名角色的立绘、战场小人和头像，以及一块场景地表。逐项统一人体、布料、线条、光照、透视和色彩，避免每张图自行变化。
2. 逐角色锁定身份。为脸型、年龄、发型、服装剪裁、兵器长度和挂件位置建立记录。以固定参照生成多视图和表情，不只靠重复同一段提示词保持一致。
3. 按用途生产素材。立绘保留面部与材质细节；小人优先保留轮廓、动作和兵器；地形按可拼接模块生产；界面文字由游戏排版，按钮和边框按九宫格需求制作。
4. 制作交付版本。整理透明边缘、脚底锚点、裁切区域、文件命名、来源和版本，针对实际用途导出。高分辨率原图与运行时版本分开保存。
5. 在实际场景验收。检查角色是否踩准格子、前后遮挡是否正确、地形能否拼接、选择框是否清楚、界面是否遮住动作。放大图精细不等于缩小后可用。
6. 继续制作多朝向与动作。逐帧核对面容、左右手、持剑方式、衣摆和光源。单张生成无法代替完整动画制作与验收。

# Audio assets

All clips are **44.1 kHz Ogg Vorbis**. Placeholder files are generated by `tools/gen_sfx.py` and can be replaced in place with real recordings — keep the **exact file names** below.

## Buses

| Bus | Use |
|-----|-----|
| `Master` | Output |
| `BGM` | Music (`bgm_battle_loop`) |
| `SFX` | One-shots + ambience |

`AudioManager` (autoload) creates these buses at runtime if missing.

## File map

### `audio/sfx/`

| File | When it plays |
|------|----------------|
| `ui_tap.ogg` | Generic UI press |
| `ui_confirm.ogg` | Confirm / start |
| `ui_cancel.ogg` | Cancel / back / undo |
| `unit_select.ogg` | Inspect / select a unit |
| `move_step_grass.ogg` | Footstep on grass/forest/snow |
| `move_step_stone.ogg` | Footstep on stone/ruins/bridge |
| `move_step_water.ogg` | Footstep on ford (shallow) |
| `atk_sword.ogg` | Melee / lance / staff swing |
| `atk_bow.ogg` | Bow attacks |
| `atk_shield.ogg` | Guard skill |
| `hit_flesh.ogg` | Successful damage hit |
| `hit_block.ogg` | Hit against a guarding unit |
| `crit.ogg` | Back attack / heavy finishing blow |
| `heal.ogg` | Heal effects |
| `skill_cast.ogg` | Magic / special cast |
| `unit_down.ogg` | Unit death |
| `turn_start_ally.ogg` | Player turn banner |
| `turn_start_enemy.ogg` | Enemy turn |
| `victory.ogg` | Battle won |
| `defeat.ogg` | Battle lost |
| `amb_night_wind.ogg` | Soft looping battle ambience |

### `audio/bgm/`

| File | When it plays |
|------|----------------|
| `bgm_battle_loop.ogg` | Battle music (looping; single player — pause/resume will not stack) |

## Regenerating placeholders

```bash
python3 tools/gen_sfx.py
godot --headless --path . --import
```

## Swapping real assets

1. Export/replace the matching `.ogg` at 44.1 kHz.
2. For looping beds (`bgm_battle_loop`, `amb_night_wind`), prefer seamless loops; `AudioManager` sets `loop = true` on load.
3. No code changes needed if names match this table.

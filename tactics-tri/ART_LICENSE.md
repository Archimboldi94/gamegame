# 美术资源许可 / Art License

《天平之誓》中的全部美术资源（地形图块、单位小人、职业图标、界面按钮与面板、朝向箭头、背景图、应用图标）
均由本仓库中的 `tools/gen_art.py`、`tools/gen_battle_art.py` 与共享绘制库 `tools/miniature.py` 使用 Python + Pillow **以程序方式自行生成**，
没有使用、描摹或改编任何第三方作品（包括任何商业游戏）的图像、角色、名称、剧情、音乐或文本。

重新生成：

```bash
python3 tools/gen_art.py
# 仅重新生成战场、人物、肖像、界面与地格特效
python3 tools/gen_art.py --battle-only
```

战斗界面的整体排版参考经典等距战棋的表现方式；视觉采用波斯细密画的矿物色、装饰平涂、衣料花纹与金线边饰：
青金石／朱砂／翡翠配色、160×80 地格、雕刻石壁、柏树、战斗及对话肖像、羊皮纸底与界面角饰均为独立程序绘制；仅借鉴历史画种的视觉语言。
生成器不读取参考截图或任何外部美术文件，不含商业游戏中的角色、美术、名称或标志。

战斗特效（斩击弧光、投射物、粒子、地格闪光、受击白闪着色器、伤害数字等）全部由
`scripts/game/battle_fx.gd` 与 `scripts/game/unit_node.gd` 在运行时以补间动画、CPU 粒子和着色器程序化绘制，不使用任何图像素材。

生成的资源与生成脚本一同以与本项目相同的条款发布，可自由使用与修改。

唯一的第三方资源是字体 `fonts/DroidSansFallbackFull.ttf`（Droid Sans Fallback，
Copyright Google / Ascender Corporation，Apache License 2.0，详见 `fonts/NOTICE.txt`），
仅用于显示中文界面文字，不属于美术资源。

All art assets are original procedural Pillow drawings generated by `tools/gen_art.py`,
`tools/gen_battle_art.py` and `tools/miniature.py`. The Persian-miniature visual language
is interpreted through original geometry and patterns; no reference images are loaded.
No third-party artwork is used. The only bundled third-party file is the Apache-2.0 licensed font noted above.
